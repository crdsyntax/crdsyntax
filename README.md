# Hola, soy crdsyntax 👋

Desarrollador backend enfocado en **TypeScript**, **NestJS** y bases de datos (MongoDB, MySQL/TypeORM). Me gusta construir herramientas prácticas: CLIs, APIs, librerías y automatizaciones.

## 🚀 Proyectos destacados

- [**toketeo**](https://github.com/crdsyntax/toketeo) — CLI de administración de bases de datos.
- [**toketeo-landing**](https://github.com/crdsyntax/toketeo-landing) — Landing page del proyecto toketeo.
- [**templateback**](https://github.com/crdsyntax/templateback) — Plantilla práctica para APIs con TypeScript y MongoDB.
- [**gesture-studio**](https://github.com/crdsyntax/gesture-studio) — Herramienta para diseñar gestos.
- [**quick-dto**](https://github.com/crdsyntax/quick-dto) — Utilidad para generar DTOs de forma rápida.
- [**secure-file-dist**](https://github.com/crdsyntax/secure-file-dist) — Distribución segura de archivos.
- [**nestjs-socket-docs**](https://github.com/crdsyntax/nestjs-socket-docs) — Documentación de sockets con NestJS.
- [**taskmcp**](https://github.com/crdsyntax/taskmcp) — Gestión de tareas.
- [**nest-typeorm-dto**](https://github.com/crdsyntax/nest-typeorm-dto) — Plantilla NestJS + TypeORM + DTOs.
- [**nest-typeorm-queryBuilder**](https://github.com/crdsyntax/nest-typeorm-queryBuilder) — Ejemplos de query builder con TypeORM.
